# MultiQC Plugin for AbPreP
MultiQC modules to generate QC metrics and report for the AbPreP pipeline (https://github.com/leonyqw/AbPreP).

## Available modules

- `read length` for read length distribution
- `matchbox` for chain identification and extraction
- `riot` for productivity and V gene assignment and pairing

## Usage

To use this plugin in pipelines, use the container image created and stored in packages.
